# Library Management System

A modern React + Tailwind + Framer Motion admin dashboard for a library management system.

## Features

- Premium dashboard with animated KPI cards
- Login screen
- Books management module
- Members management module
- Issue tracking
- Fines and payment tracking
- Reports and analytics
- User management
- Settings section
- Responsive sidebar + top navbar

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
